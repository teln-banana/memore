# 06暗号

暗号とかなをブラウザ内で相互変換する、ダークモードの静的サイト。

- 行＋段の2桁（11＝あ、22＝き）
- 00＝ん、99＝ww
- 濁点は数字の後に `"`、半濁点は `'`
- 小文字は数字の前に `.`
- `*`の直後の1桁は数字のまま（`*12345`＝`1くと`）
- `***`から行末まではそのまま（`***12345`＝`12345`）。次の行から通常の変換に戻る
- かなから暗号へ変換するとき、実際の数字には1桁ずつ`*`を付ける
- お段は5・0の両方を読み取り、暗号化時は5を使用（00は常に「ん」）
- カタカナ・半角カナも入力可能。復号はひらがな
- 括弧・記号・改行・未対応文字は保持（`0612`＝`06い`）
- 結果の括弧内は太字で表示。コピー・方向切り替えでは括弧を保持
- 「Discord用にコピー」をオンにすると、コピー時だけ各`*`の直前に`\`を追加。設定はブラウザに保存

漢字の読み変換は行いません。入力内容はサーバーへ送信しません。

## ローカルで開く

```sh
npm start
```

http://localhost:4173 を開く。依存パッケージとビルドは不要。

## テスト

```sh
npm test
```

## GitHub Pages

リポジトリの Settings → Pages で `Deploy from a branch` を選び、`main` の `/ (root)` を指定する。ルートの静的ファイルをそのまま配信する。
